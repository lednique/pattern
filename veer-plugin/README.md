# Veer — плагин веера из изображений для Figma

Veer собирает из выделенных слоёв **веер** — дугу из изображений, которые можно изогнуть от прямой линии до полного круга. Плагин не растрирует исходники: в результирующий `Frame` попадают клоны исходных Figma-объектов. Дизайн, анимации и лицензионная архитектура повторяют Patternique.

## Возможности

- до **12 изображений** в одном веере; выделение в Figma автоматически подхватывается и капается по 12;
- **направление** стопки: влево или вправо (сегмент с анимированным глайдером);
- все ползунки, кроме наложения, **биполярные — от −100 до +100 с нулём в середине**: отрицательное значение даёт обратное воздействие, положительное — прямое;
- **начальная позиция** — точка начала движения по кругу (±180°, стрелочные часы: 0° — сверху);
- **угол сгиба** ±360°: 0° — ровная линия, +360° — замкнутый круг, минус загибает дугу в противоположную сторону;
- **размер по иерархии** — каждая следующая карточка стопки меньше (плюс) или крупнее (минус); на +100 дальняя карточка уменьшается до 40%;
- **наложение** изображений от 90% (плотная стопка) до 0% (карточки встают краем к краю);
- **случайность** тремя отдельными параметрами: сдвиг (в пределах ±125% размера контейнера каждого элемента), размер (±70%) и поворот (±180%); 0 — ровная раскладка, ±100 — полный хаос, минус зеркалит плюс; хаос детерминирован сидом и привязан к конкретному изображению — при перестановке картинка уносит свой сдвиг с собой;
- режим **«через 1»** с собственной величиной сдвига — каждое второе изображение иерархии смещается по радиусу: наружу (плюс) или внутрь (минус), ±100 = высота карточки;
- **обрезка до единой карточки** — все изображения центрируются и обрезаются до средней ширины × средней высоты набора; при выключенной обрезке сохраняются пропорции исходников;
- превью: превью-копии картинок экспортируются с размером **256 px по большей стороне**, макет автоматически масштабируется при изменении выделения; карточки рисуются со скруглением 12 px (только в интерфейсе — экспорт без скруглений) на прозрачном фоне;
- наведение на изображение — подсветка белым 40% и пружинящая анимация масштаба из центра карточки (как кнопки интерфейса);
- перетаскивание картинки внутри превью **вставляет её между соседями**: стопка в реальном времени раздвигается и пропускает карточку внутрь; **drag and drop в сцену Figma отключён** — работает только перестановка;
- ползунки меняются только при зажатой кнопке мыши: колесо и стрелки клавиатуры не сдвигают значения;
- **20 шаблонов** слева и **рандомайзер** справа от превью; шаблоны нарисованы схематично — пять карточек заливкой от белого (ближние по слоям) до тёмно-серого (дальние), сами изображения не используются;
- окно плагина шириной **600 px** (на 200 px шире Patternique), параметры настроек в две колонки;
- оранжевая палитра `#F2A24C`, логотип LEDNIQUE рядом с заголовком, Montserrat, 7 языков интерфейса;
- 5 бесплатных созданий, затем активация лицензии через собственный сайт плагина **veer.lednique.ru**: год — **290 ₽**, навсегда — **790 ₽** (отдельные база и личный кабинет, не зависят от Patternique).

## Экспорт

- все изображения помещаются в **один прозрачный фрейм** `Veer · fan`, размер которого равен охватывающему прямоугольнику веера;
- к названиям картинок добавляется префикс с порядковым номером: `01_veer_…`, `02_veer_…` … `12_veer_…`;
- в режиме обрезки каждая картинка лежит в собственной рамке-карточке, которая обрезает клон по единому размеру;
- настройки сохраняются в plugin data фрейма (`veerSettings`) и в `clientStorage` пользователя; исходные объекты не изменяются.

## Сборка и тесты

```bash
cd veer-plugin
bash build.sh
node test/core.test.js
node test/sandbox.test.js
node test/ui.test.js
```

`build.sh` собирает:

- `code.js` из `src/code-template.js` и общей математики `src/veer-core.js`;
- `ui.html` из `src/ui-template.html`, общей математики, встроенного Montserrat и логотипов.

## Установка для разработки

1. Откройте Figma Desktop.
2. **Plugins → Development → Import plugin from manifest…**
3. Выберите `veer-plugin/manifest.json`.
4. Выделите от 1 до 12 слоёв и запустите Veer.

## Перед публикацией

- Получите постоянный ID плагина в Figma и замените development ID в `manifest.json`.
- Домен лицензирования и `SITE_URL` — `https://veer.lednique.ru` (каталог `veer-backend/`).
- После изменения исходников всегда публикуйте собранные `code.js` и `ui.html`.
