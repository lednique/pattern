# Patternique — плагин бесшовных узоров для Figma

Patternique создаёт редактируемый бесшовный тайл из одного или двух выделенных слоёв. Плагин не растрирует исходники: в результирующем `Frame` находятся клоны исходных Figma-объектов.

## Возможности

- обычная сетка;
- повторение с последовательным поворотом;
- шахматный режим:
  - одна фигура через ячейку;
  - одна фигура с двумя наборами размера, цвета и поворота;
  - две разные выделенные фигуры;
- отдельный цвет и размер каждого варианта;
- цвет фона тайла;
- горизонтальный сдвиг каждой второй строки;
- вертикальный сдвиг каждой второй колонки;
- элементы на пересечениях обычной сетки: перекрестие, четырёхгранная звезда, круг, символ или линия;
- live-preview;
- 5 бесплатных созданий, затем активация ключа;
- лицензия на год или бессрочная лицензия.

Для шахматного режима и сдвигов число строк/столбцов автоматически округляется до чётного. Это сохраняет фазу при копировании тайла вплотную по горизонтали и вертикали. Фигуры за краями дублируются с запасом и обрезаются фреймом, поэтому сдвинутые элементы корректно продолжаются на соседнем тайле.

## Сборка

```bash
cd pattern-plugin
bash build.sh
node test/core.test.js
```

`build.sh` собирает:

- `code.js` из `src/code-template.js` и общей математики `src/pattern-core.js`;
- `ui.html` из `src/ui-template.html`, общей математики и встроенного логотипа LEDNIQUE.

## Установка для разработки

1. Откройте Figma Desktop.
2. **Plugins → Development → Import plugin from manifest…**
3. Выберите `pattern-plugin/manifest.json`.
4. Выделите один слой или два слоя для шахматного режима и запустите Patternique.

## Перед публикацией

- Получите постоянный ID плагина в Figma и замените development ID в `manifest.json`.
- Если сайт лицензирования размещён не на `https://pattern.lednique.ru`, замените `SITE_URL` в `src/ui-template.html` и домен в `manifest.json`, затем выполните `bash build.sh`.
- После изменения исходников всегда публикуйте собранные `code.js` и `ui.html`.

## Архитектура результата

Плагин создаёт Frame с `clipsContent = true`, фоновой заливкой и клонами выбранных слоёв. Настройки сохраняются в plugin data фрейма (`patterniqueSettings`) и в `clientStorage` пользователя. Исходные объекты не изменяются.
