# Patternique — плагин бесшовных узоров для Figma

Patternique создаёт редактируемый бесшовный тайл **256 × 256 px** из одного или двух выделенных слоёв. Плагин не растрирует исходники: в результирующем `Frame` находятся клоны исходных Figma-объектов.

## Возможности

- фиксированный паттерн 256 × 256 px с настройкой количества строк и столбцов;
- обычная сетка и повторение с последовательным поворотом;
- два шахматных режима `1` и `2`, встроенные прямо в кнопку режима;
- чередование двух выделенных фигур с отдельными цветом, поворотом и размером до 150%;
- «сетка в полразмера» для сеток от трёх элементов: не добавляет дубликаты, а перекомпоновывает существующие фигуры — каждый второй ряд или колонка располагается между соседними ячейками; горизонтальное и вертикальное направление включаются отдельно;
- одновременный горизонтальный и вертикальный сдвиг через один;
- цвет фона тайла;
- элементы на пересечениях: перекрестие, четырёхгранная звезда, круг, символ или линия;
- блок элементов на пересечениях показывается только в режиме «Шахматы»; по умолчанию выбрана четырёхгранная звезда размером 25;
- закреплённый предпросмотр в масштабе 100%, исходный градиент темы и отдельный фоновый узор с прозрачностью 50%; при прокрутке позади центрального квадрата появляется дополнительный градиент перед карточками настроек;
- drag and drop центрального квадрата прямо в сцену Figma;
- значения слайдеров меняются кликом по треку, стрелками клавиатуры или прямым вводом значения;
- системный выбор цвета Apple/Windows с вызовом нативной панели через `showPicker()` и поддержкой Display P3;
- клоны сохраняют исходные fill, stroke, opacity, inner/drop shadow и другие эффекты; изменение цвета заменяет только сплошные заливки;
- предпросмотр учитывает `absoluteRenderBounds` эффектов и использует тот же коэффициент масштабирования, что и экспорт в Figma;
- заголовок с предоставленным SVG-знаком, Patternique 24 px Medium, объёмные внутренние/внешние тени активных режимов и pill-ползунки 22 × 14 px;
- стартовые значения: сетка 4 × 4, сдвиг колонок 50/0, поворот −15°, объекты 70%/0° и 40%/180°, звезда на пересечении размером 25;
- интерфейс на Montserrat, тема `#DEDD74`;
- 7 языков: English, Русский, Italiano, Português, Français, 中文, 日本語;
- 5 бесплатных созданий, затем активация годовой или бессрочной лицензии.

Фигуры за краями дублируются с запасом и обрезаются фреймом, поэтому элементы корректно продолжаются на соседнем тайле.

## Сборка и тесты

```bash
cd pattern-plugin
bash build.sh
node test/core.test.js
node test/sandbox.test.js
node test/ui.test.js
```

`build.sh` собирает:

- `code.js` из `src/code-template.js` и общей математики `src/pattern-core.js`;
- `ui.html` из `src/ui-template.html`, общей математики, встроенного Montserrat и логотипов.

## Установка для разработки

1. Откройте Figma Desktop.
2. **Plugins → Development → Import plugin from manifest…**
3. Выберите `pattern-plugin/manifest.json`.
4. Выделите один слой или два слоя для шахматного режима и запустите Patternique.

## Перед публикацией

- Получите постоянный ID плагина в Figma и замените development ID в `manifest.json`.
- Если сайт лицензирования размещён не на `https://pattern.lednique.ru`, замените `SITE_URL` в `src/ui-template.html` и домен в `manifest.json`, затем выполните `bash build.sh`.
- После изменения исходников всегда публикуйте собранные `code.js` и `ui.html`.

## Архитектура результата

Плагин создаёт Frame 256 × 256 px с `clipsContent = true`, фоновой заливкой и клонами выбранных слоёв. Настройки сохраняются в plugin data фрейма (`patterniqueSettings`) и в `clientStorage` пользователя. Исходные объекты не изменяются.
